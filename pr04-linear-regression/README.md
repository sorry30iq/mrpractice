# Практическая работа 4. Машинное обучение. Линейная регрессия.

**Цель:** получение практических навыков реализации моделей и алгоритмов
машинного обучения.

## Содержимое

| Файл | Что реализовано |
|---|---|
| `linear_regression_manual.py` | п.3.1-3.2 — генерация датасета + регрессия вручную через градиентный спуск |
| `linear_regression_sklearn.py` | п.3.3 — та же задача через sklearn, для сравнения |
| `bonus_sin_regression.py` | Доп. задание — аппроксимация sin(x) полиномиальной регрессией |
| `LinearRegressionJava.java` | Java-версия ручной реализации (методичка явно разрешает "выбранный ЯП") |
| `*.png` | графики (сгенерированы при запуске) |

Ответы на теоретические вопросы (п.1.2, 2.3) — в `../docs/pr04_answers.md`.

## Как запустить

```bash
pip install numpy matplotlib scikit-learn
python3 linear_regression_manual.py
python3 linear_regression_sklearn.py
python3 bonus_sin_regression.py

# Java-версия (бонус)
javac LinearRegressionJava.java && java LinearRegressionJava
```

## Результаты (проверено при сборке репозитория)

- Ручная реализация (100 эпох, lr=0.01) не успевает полностью сойтись к
  истинным a=2, b=1: получает a≈1.397, b≈0.820 — совпадает с цифрами из
  методички один в один (это нормально, показывает влияние числа эпох).
- sklearn (аналитическое решение МНК) сразу находит точные параметры:
  b=0.9860, a=1.9868 — тоже совпадает с методичкой.
- Bonus (sin(x), полином степени 7): R² ≈ 0.95 на тестовой выборке.
