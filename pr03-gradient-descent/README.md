# Практическая работа 3. Алгоритм градиентного спуска.

**Цель:** исследование методов решения оптимизационных задач, изучение
алгоритма градиентного спуска.

## Содержимое

| Файл | Что реализовано |
|---|---|
| `gradient_descent_1d.py` | п.4.2 — АГС для f(x) = (x-a)² + sin(3(x-a)) + b |
| `gradient_descent_2d.py` | п.4.3 — АГС для функции двух переменных на области [-3,3]×[-3,3] |
| `gradient_descent_1d.png` | график функции + траектория спуска (сгенерирован) |
| `gradient_descent_2d.png` | 3D-поверхность функции (сгенерирован) |

Ответы на теоретические вопросы (п.1.2, 2.2) и разбор примера кода из
методички — в `../docs/pr03_answers.md`.

## Как запустить

```bash
pip install numpy matplotlib
python3 gradient_descent_1d.py
python3 gradient_descent_2d.py
```

## Результаты (проверено при сборке репозитория)

`gradient_descent_1d.py` при a=2.4, b=4.8, x0=5, lr=0.1, 30 итераций
сходится к x≈3.64459, f(x)≈5.79084 — **совпадает с точкой C на графике
DESMOS из методички** (п.3.2), это хорошая проверка правильности реализации.

`gradient_descent_2d.py` — функция невыпуклая, поэтому в коде АГС
запускается из нескольких стартовых точек и выбирается лучший найденный
минимум (это стоит явно проговорить на защите — типичная особенность АГС
на невыпуклых функциях).
