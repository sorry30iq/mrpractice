# Практическая работа 1. Математическое моделирование. Численные методы.

**Цель:** получение практических навыков аналитического и численного
моделирования на примерах исследования различных моделей объектов
реального мира.

## Содержимое

| Файл | Что реализовано |
|---|---|
| `1_ball_movement.html` | п.1.3 — движение шарика слева направо (p5js) |
| `2_population_growth.html` | п.3 — модель роста народонаселения, y' = ky, метод Эйлера |
| `3_hooke_law.html` | п.4 — закон Гука, m·x'' = -k·x (+ затухание), метод Эйлера |

Ответы на теоретические вопросы (п.2.3, 3.3, 4.3) — в `../docs/pr01_answers.md`.

## Как запустить

Каждый `.html` файл самодостаточен — просто открой его в браузере
(двойной клик или через "Открыть с помощью"). Библиотека p5.js подключается
через CDN (`cdnjs.cloudflare.com`), поэтому нужен интернет при первом
открытии, локально ничего ставить не нужно.

В каждом файле можно менять параметры модели прямо в коде (`<script>` внутри
HTML) — k, h, начальные условия — и смотреть, как меняется поведение.
