# Оценка сложности алгоритмов

Java-решения четырёх классических задач с обоснованием сложности по O.

| Файл | Задача | Оптимальная сложность |
|---|---|---|
| `src/Anagram.java` | Проверка анаграммы | O(n) по времени (частотный подсчёт через HashMap) |
| `src/TwoSum.java` | Пара чисел с суммой k | O(n) по времени (HashMap "значение → индекс") |
| `src/PalindromeNumber.java` | Числовой палиндром | O(log₁₀ n) — по числу цифр |
| `src/BalancedBrackets.java` | Баланс скобок | O(n) по времени (стек, Deque) |

Каждый файл содержит и наивное, и оптимальное решение (где это уместно) —
для сравнения и обоснования выбора на защите.

## Запуск

```bash
cd src
javac *.java
java Anagram
java TwoSum
java PalindromeNumber
java BalancedBrackets
```
