# MASEPS — подготовка к пересдаче

Репозиторий с кодом ко всем практическим работам курса (математическое
моделирование и элементы прикладной статистики / МО), плюс отдельный блок
задач на оценку сложности алгоритмов.

## Структура

```
algo-complexity/         Java: 4 задачи на Big O (анаграмма, two sum, палиндром, скобки)
pr01-euler-method/       JS/p5js: метод Эйлера (шарик, рост популяции, закон Гука)
pr02-linear-programming/ Python (scipy): 4 задачи линейного программирования
pr03-gradient-descent/   Python: градиентный спуск, 1D и 2D
pr04-linear-regression/  Python + Java: линейная регрессия (руками, sklearn, bonus sin(x))
pr07-classification/     Python (sklearn): банковский скоринг, сравнение моделей
pr08-neural-networks/    Python (keras): Dense-сеть и CNN на MNIST
docs/                    Ответы на теоретические вопросы из методичек по каждой работе
requirements.txt         Python-зависимости для всех практик, кроме ПР1 (JS) и ПР4-java/algo (Java)
```

Внутри каждой `prXX-.../` папки — свой `README.md` с официальным названием
работы, списком файлов и командами запуска, так что при желании можно
отправлять преподу даже отдельную папку одной практики, а не весь репозиторий.

## Как запускать

### Python-практики (ПР2, ПР3, ПР4, ПР7, ПР8)

```bash
pip install -r requirements.txt

python3 pr02-linear-programming/task1_lopaty.py
python3 pr03-gradient-descent/gradient_descent_1d.py
python3 pr04-linear-regression/linear_regression_manual.py
python3 pr07-classification/bank_scoring.py     # см. примечание про датасет ниже
python3 pr08-neural-networks/dense_mnist.py     # требует доступ в интернет для скачивания MNIST
```

### ПР1 (p5js)

Просто открой любой `.html` файл из `pr01-euler-method/` в браузере —
всё самодостаточно, p5.js подключается через CDN, ничего ставить не нужно.

### Java (algo-complexity, ПР4 bonus)

```bash
cd algo-complexity/src && javac *.java && java Anagram   # и т.д.
cd pr04-linear-regression && javac LinearRegressionJava.java && java LinearRegressionJava
```

## Важные примечания

- **ПР7 (bank_scoring.py):** нужен настоящий датасет `bank-additional-full.csv`
  (ссылка на UCI — в комментарии к скрипту). Без него скрипт автоматически
  подставляет синтетические данные той же структуры, чтобы пайплайн можно
  было проверить — но для защиты нужны реальные цифры на настоящем
  датасете, а не на синтетике.
- **ПР8 (keras):** при первом запуске `mnist.load_data()` скачивает датасет
  из интернета — на месте, где собирался этот репозиторий, доступа к этому
  хосту не было, поэтому сами скрипты запускались и проверялись на
  синтетических данных той же формы (архитектура и число параметров модели
  подтверждённо совпадает с методичкой: 407 050 для Dense-модели и 93 322
  для CNN). У тебя дома/в вузе с обычным интернетом скрипт скачает MNIST
  и отработает от начала до конца сам.
- **algo-complexity (Java):** код синтаксически проверен вручную (в
  контейнере, где собирался репозиторий, не было `javac`), логика
  протестирована built-in тест-кейсами в каждом `main()` — но перед защитой
  стоит самому прогнать `javac` + `java`.
- Все Python-скрипты (кроме bank_scoring.py и keras-скриптов) полностью
  протестированы и воспроизводят числа из методичек (например, ПР3:
  x=3.64459 — совпадает с точкой C на графике DESMOS в методичке; ПР4:
  sklearn даёт b=0.9860, a=1.9868 — то же самое, что в методичке).

## docs/ — ответы на теоретические вопросы

В каждой практической есть блок "ответьте на вопросы" — краткие, но полные
ответы на них собраны в `docs/pr0X_answers.md` для соответствующей работы.
Не скопированы дословно из методички, а сформулированы своими словами —
рекомендую пробежаться перед защитой и при необходимости адаптировать под
свои слова.

## Порядок подготовки (рекомендованный)

1. `algo-complexity/` — разминка, код уже понятен как Java-разработчику
2. `pr02-linear-programming/` — задачи решаются "руками" через scipy
3. `pr01-euler-method/` — непривычный стек (JS/p5js), но логика простая
4. `pr03-gradient-descent/` — концептуальная база для ПР4/7/8
5. `pr04-linear-regression/` — три версии одной задачи + bonus на Java
6. `pr07-classification/` — самая объёмная по коду часть
7. `pr08-neural-networks/` — завершающая, использует наработки из ПР7
