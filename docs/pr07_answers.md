# ПР7. Классификационные модели машинного обучения — ответы на вопросы

**Что такое задача классификации, чем отличается от регрессии?**
В классификации целевая переменная — категориальная (принадлежность к
одному из конечного числа классов: "да/нет", "спам/не спам"), в регрессии —
непрерывная числовая величина. Соответственно различаются и функции потерь,
и метрики качества.

**Какие классификационные модели вы знаете?**
Логистическая регрессия, метод k ближайших соседей (kNN), деревья решений,
случайный лес (Random Forest), градиентный бустинг (Gradient Boosting,
XGBoost), метод опорных векторов (SVM), наивный байесовский классификатор,
нейросети.

**Функция потерь при бинарной / многозначной классификации:**
- Бинарная классификация: binary crossentropy (логистическая функция потерь).
- Многоклассовая (однозначная) классификация: categorical crossentropy.

**Что такое категориальный признак, методы его кодирования?**
Признак, принимающий значения из конечного неупорядоченного (или
упорядоченного) набора категорий, а не число (например, "профессия",
"семейное положение"). Методы кодирования:
- One-Hot Encoding (`pd.get_dummies`) — каждая категория превращается в
  отдельный бинарный столбец; используется в нашем bank_scoring.py.
- Label Encoding — каждой категории присваивается целое число (подходит
  для деревьев решений, но может ввести в заблуждение линейные модели
  из-за "мнимого порядка" между категориями).
- Target/Mean Encoding — категория заменяется средним значением целевой
  переменной по этой категории (эффективно, но требует аккуратности из-за
  риска утечки данных/переобучения).

**Как измеряется качество классификационной модели?**
Через матрицу ошибок и производные от неё метрики: accuracy, precision,
recall, F1-score, ROC-AUC — см. ниже.

**Что такое матрица ошибок, какие метрики вы знаете?**
Таблица 2x2 (для бинарной классификации), сопоставляющая предсказанный и
истинный класс: TP (True Positive), TN (True Negative), FP (False Positive —
ложная тревога), FN (False Negative — пропуск). Метрики:
- accuracy = (TP+TN)/(TP+TN+FP+FN) — доля верных ответов (ненадёжна при
  дисбалансе классов).
- precision = TP/(TP+FP) — точность: из предсказанных положительными,
  сколько реально положительные.
- recall = TP/(TP+FN) — полнота: из реально положительных, сколько нашли.
- F1 = 2*precision*recall/(precision+recall) — баланс между ними.
- ROC-AUC — площадь под ROC-кривой (TPR от FPR при разных порогах),
  показывает качество ранжирования моделью объектов по вероятности класса.
