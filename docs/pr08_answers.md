# ПР8. Нейросетевые модели машинного обучения — ответы на вопросы

**Что такое функция потерь, для чего она применяется?**
Функция, измеряющая расхождение между предсказанием сети и истинным
значением на обучающем примере. Используется как сигнал для обратного
распространения ошибки (backpropagation) — по ней вычисляются градиенты,
на основе которых обновляются веса сети.

**Что такое функция активации (последнего слоя)?**
Нелинейное преобразование выхода последнего слоя сети, приводящее "сырые"
числа (логиты) к виду, подходящему под конкретную задачу — например,
к вероятностям классов.

**Какую функцию активации использовать при бинарной классификации?**
sigmoid — сжимает выход в диапазон (0,1), интерпретируется как вероятность
положительного класса. В паре с loss = binary_crossentropy.

**Какую — при многозначной (многоклассовой) классификации?**
softmax — превращает вектор логитов в распределение вероятностей по всем
классам (сумма = 1). В паре с loss = categorical_crossentropy. Именно она
используется в наших моделях dense_mnist.py и cnn_mnist.py (10 классов
цифр).

**Смысл создания многослойной (глубокой) нейронной сети, преимущество?**
Каждый следующий слой строит более сложные, абстрактные признаки поверх
признаков предыдущего слоя (например, в CNN: первые слои находят края и
текстуры, следующие — из них собирают формы, а глубокие — целые объекты).
Многослойная сеть способна приближать существенно более сложные,
нелинейные зависимости, чем один слой (одиночный линейный слой в принципе
не может выучить нелинейно разделимые классы).

**Что такое эпоха обучения?**
Один полный проход обучающего алгоритма по всей обучающей выборке.
В dense_mnist.py используется 5 эпох (epochs=5).

**Что такое размер пакета (batch size)? Как влияет на обучение?**
Количество примеров, после обработки которых веса сети обновляются один
раз (а не после каждого отдельного примера или после всей выборки сразу).
Маленький batch size → более "шумные", но частые обновления весов (может
помогать выбираться из локальных минимумов, но обучение менее стабильно).
Большой batch size → более точная оценка градиента на каждом шаге, но
обновлений меньше и они дороже по памяти/вычислениям.

**Что такое шаг обучения (learning rate)? Как влияет?**
Коэффициент, определяющий величину шага изменения весов на каждой
итерации градиентного спуска (см. также docs/pr03_answers.md). Слишком
маленький → медленное обучение, слишком большой → неустойчивое обучение
или расхождение loss.

## Раздел 2-3: полносвязная (Dense) модель на MNIST

**Датасет:** MNIST — 60000 обучающих и 10000 тестовых изображений
рукописных цифр 28x28 пикселей в градациях серого, с метками 0-9.

**Структура модели:** Dense(512, relu) → Dense(10, softmax).
Входной слой разворачивает изображение 28x28 в плоский вектор из 784
чисел. Всего 407 050 обучаемых параметров.

**Функция потерь и активация последнего слоя:** categorical_crossentropy
+ softmax (многоклассовая однозначная классификация, 10 цифр).

**Число эпох:** 5.

**Качество / метрика:** оценивается по accuracy (доле верно распознанных
цифр) на тестовой выборке; в методичке — 0.9785 (97.85%).

## Раздел 4: свёрточная (CNN) модель

Архитектура: Conv2D(32)→MaxPool→Conv2D(64)→MaxPool→Conv2D(64)→Flatten→
Dense(64, relu)→Dense(10, softmax). Всего 93 322 параметра — меньше, чем
у полносвязной модели, но точность выше (0.9916 против 0.9785 в
методичке), т.к. свёртка использует локальную пространственную структуру
изображения (соседние пиксели образуют осмысленные признаки — края,
углы, штрихи), а не работает с изображением как с "плоским" набором
несвязанных чисел, как это делает Dense-слой.
