# ПР4. Машинное обучение. Линейная регрессия — ответы на вопросы

**Что такое обучающий набор данных (датасет)?**
Набор примеров (объектов), на которых модель учится находить закономерность.
Каждый пример обычно состоит из признаков (входных характеристик объекта) и,
для обучения с учителем, — правильного ответа (метки).

**Какой тип датасета используется при обучении с учителем?**
Размеченный (labeled) датасет — каждому объекту сопоставлена известная
правильная метка/значение (то, что модель должна научиться предсказывать).

**Кто такой "учитель"?**
Метафора: "учитель" — это те самые правильные ответы (метки) в обучающей
выборке, по которым модель сверяет свои предсказания и корректирует
параметры (по аналогии с учеником, которого поправляет учитель).

**Что такое функция потерь?**
Функция, измеряющая, насколько сильно предсказание модели отличается от
истинного значения. Чем меньше значение функции потерь — тем лучше модель
приближает данные. Для регрессии типично MSE (среднеквадратичная ошибка).

**Что значит переобучить модель?**
Модель настолько точно подстроилась под обучающую выборку (включая шум и
случайные отклонения в ней), что теряет способность обобщать закономерность
на новые, ранее не виденные данные — на тесте показывает существенно худший
результат, чем на обучении.

## Типы задач МО

**Какие основные типы задач решаются с помощью моделей МО?**
Обучение с учителем (регрессия, классификация), обучение без учителя
(кластеризация, снижение размерности), обучение с подкреплением.

**Для какого типа задач целесообразна линейная регрессия?**
Для задач регрессии — предсказания непрерывной числовой величины, когда
зависимость между признаками и целевой переменной приближённо линейна
(цена квартиры от площади, температура от времени суток и т.д.).

**Для какого типа задач целесообразна логистическая регрессия?**
Для задач бинарной (или, в расширении — многоклассовой) классификации:
несмотря на название "регрессия", на выходе модель через sigmoid-функцию
даёт вероятность принадлежности к классу, а не непрерывное число.

**Для чего применяется градиентный спуск при обучении модели?**
Для итеративного подбора параметров модели (в линейной регрессии — a и b),
минимизирующих функцию потерь на обучающей выборке, когда аналитическое
решение либо отсутствует, либо слишком затратно вычислительно (актуально
для сложных моделей вроде нейросетей, где аналитического решения нет).

## Наши результаты (linear_regression_manual.py / _sklearn.py)

Ручная реализация через 100 эпох градиентного спуска (lr=0.01) не успевает
полностью сойтись к истинным параметрам (a=2, b=1), получая a≈1.40, b≈0.82 —
это нормально и наглядно показывает влияние числа итераций и learning rate
на сходимость. Реализация через sklearn (`LinearRegression`, аналитическое
решение по методу наименьших квадратов) сразу находит точные параметры
(a≈1.987, b≈0.986), что подтверждает корректность модели и данных.
