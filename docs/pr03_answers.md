# ПР3. Алгоритм градиентного спуска — ответы на вопросы

## 1. Постановка задачи оптимизации

**Что представляет собой график функции f(x̄) = 2x1 + 3x2?**
Это линейная функция двух переменных — её график представляет собой
плоскость в трёхмерном пространстве (x1, x2, f).

**Как задать ограничения на область определения в виде треугольника?**
Треугольник задаётся системой из трёх линейных неравенств — каждое
неравенство "отрезает" полуплоскость по одной из сторон треугольника,
а их пересечение и образует треугольную область. Например:
x1 >= 0, x2 >= 0, x1 + x2 <= 1 задают треугольник с вершинами (0,0),(1,0),(0,1).

**Что значит решить задачу оптимизации функции f(x̄)?**
Найти такую точку (или множество точек) x̄* в допустимой области, в которой
функция f принимает минимальное (или максимальное — в зависимости от
постановки) значение среди всех точек этой области.

**Примеры оптимизационных задач:**
максимизация прибыли предприятия при ограниченных ресурсах (ПР2), минимизация
функции потерь при обучении модели МО, поиск кратчайшего маршрута,
оптимальное распределение бюджета рекламной кампании.

## 2. Алгоритм градиентного спуска (АГС)

**Что такое АГС, для чего используется?**
Итеративный численный метод поиска локального минимума функции. На каждом
шаге текущая точка сдвигается в направлении, противоположном градиенту
функции в этой точке (т.к. градиент указывает направление наискорейшего
роста функции). Используется прежде всего для обучения моделей машинного
обучения — поиска параметров, минимизирующих функцию потерь.

**Что такое градиент функции (в точке)?**
Вектор из частных производных функции по каждой переменной:
∇f(x,y) = (∂f/∂x, ∂f/∂y). Указывает направление наискорейшего возрастания
функции в данной точке.

**Что такое шаг итерации в АГС (learning rate), на что он влияет?**
Коэффициент, на который умножается градиент перед вычитанием из текущей
точки: x_new = x - lr*∇f(x). Слишком маленький lr → медленная сходимость
(нужно много итераций). Слишком большой lr → алгоритм может "перескакивать"
через минимум и расходиться (не сойтись вообще).

**Достоинства и недостатки АГС:**
- Плюсы: универсален (работает для широкого класса функций), просто
  реализуется, хорошо масштабируется на функции с большим числом переменных
  (в отличие от полного перебора).
- Минусы: может застревать в локальном минимуме (не гарантирует глобальный,
  особенно на невыпуклых функциях), чувствителен к выбору шага lr и
  начальной точки, для плохо обусловленных функций сходится медленно
  ("зигзагами").

## 3. Разбор примера кода (numpy gradient_descent)

Шаг итерации в примере кода задаётся параметром `step_size = 0.1`.
Количество итераций задаётся параметром `n_iter = 30`.
Начальная точка выбирается случайно в границах `bounds` через
`rand(len(bounds)) * (bounds[:,1] - bounds[:,0]) + bounds[:,0]`.
На каждой итерации: считается градиент через `derivative()`, точка сдвигается
против градиента на `step_size`, и вычисляется значение целевой функции для
отчёта о прогрессе.
