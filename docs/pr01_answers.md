# ПР1. Математическое моделирование. Численные методы — ответы на вопросы

**Что такое функция?**
Правило (закон соответствия), которое каждому элементу из множества входных
значений (аргументов) ставит в соответствие ровно одно значение из множества
выходных значений: y = f(x).

**Какие типы функций вы знаете?**
Линейные, квадратичные, степенные, показательные (экспоненциальные),
логарифмические, тригонометрические, кусочные; также по свойствам —
непрерывные/разрывные, монотонные, периодические, чётные/нечётные.

**Что такое производная функции (в точке)?**
Предел отношения приращения функции к приращению аргумента при стремлении
приращения аргумента к нулю: f'(x) = lim(Δx→0) [f(x+Δx) - f(x)] / Δx.
Геометрически — это угловой коэффициент касательной к графику функции в точке,
физически — мгновенная скорость изменения величины.

**Что такое дифференциальное уравнение?**
Уравнение, связывающее независимую переменную, неизвестную функцию и её
производные. Пример: y' = ky.

**Что является решением дифференциального уравнения?**
Функция (а не число), которая при подстановке в уравнение обращает его в
тождество. У ДУ обычно есть семейство решений, конкретное решение выделяется
начальными условиями.

**Что такое шаг при численном моделировании?**
Величина, на которую увеличивается независимая переменная (обычно время t)
на каждой итерации численного метода (например, метода Эйлера). Чем меньше
шаг h, тем точнее приближение к истинному решению, но тем больше вычислений
нужно совершить.

**Для чего нужны начальные условия?**
Дифференциальное уравнение само по себе имеет бесконечно много решений
(семейство кривых). Начальные условия (значение функции в начальный момент
времени) фиксируют конкретное решение из этого семейства.

## Модель роста народонаселения (y' = ky)

**Какая функция является решением?**
Экспонента: y(t) = y0 * e^(k*t), где y0 — начальная численность.

**Как влияют параметры k и h на решение?**
- k > 0 — рост, k < 0 — убывание, чем больше |k| — тем быстрее изменение.
- h (шаг метода Эйлера) — влияет только на точность численного приближения:
  при слишком большом h численное решение может заметно отклоняться от
  истинной экспоненты (и даже "расходиться" при очень грубом шаге).

**Что такое экспонента?**
Функция вида e^x (или a^x), у которой скорость роста пропорциональна
текущему значению самой функции — отсюда и связь с уравнением y' = ky.

**Примеры экспоненциального роста:**
рост числа пользователей вирусного приложения на старте, распространение
эпидемии на ранней стадии, начисление сложных процентов по вкладу,
цепная реакция.

## Физическая модель — закон Гука (mx'' = -kx)

**Какая функция является решением?**
Гармоническое колебание: x(t) = A*cos(ω*t + φ), где ω = sqrt(k/m) —
собственная частота колебаний, A и φ определяются начальными условиями.

**Как влияют параметры k и h?**
- k (жёсткость пружины) — чем больше k, тем выше частота колебаний
  (колебания "быстрее").
- h — как и выше, шаг численного интегрирования; слишком большой h у
  колебательных систем особенно опасен — решение может "раскачаться" и
  разойтись (потерять устойчивость), даже если физически колебания должны
  быть ограниченными.

**Как сделать колебания затухающими?**
Добавить в уравнение силу сопротивления (трения), пропорциональную скорости:
m*x'' = -k*x - c*x', где c > 0 — коэффициент затухания. Реализовано в
3_hooke_law.html через переменную c.
