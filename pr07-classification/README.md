# Практическая работа 7. Классификационные модели машинного обучения.

**Цель:** получение практических навыков создания, обучения и оценки
качества классификационных моделей машинного обучения.

## Содержимое

| Файл | Что реализовано |
|---|---|
| `bank_scoring.py` | Полный пайплайн: загрузка данных, кодирование признаков, LogisticRegression, GradientBoostingClassifier, метрики, матрица ошибок, ROC-AUC |
| `confusion_matrix_gbc.png` | матрица ошибок для Gradient Boosting (сгенерирован) |
| `roc_curve.png` | ROC-кривая для обеих моделей (сгенерирован) |

Ответы на теоретические вопросы (п.1.2) — в `../docs/pr07_answers.md`.

## ⚠️ Перед запуском: нужен настоящий датасет

Скачай `bank-additional-full.csv` по ссылке из методички:
https://archive.ics.uci.edu/dataset/222/bank+marketing

и положи файл в эту же папку. **Без файла скрипт автоматически подставит
синтетические данные** той же структуры (чтобы пайплайн можно было
проверить без датасета) — но для защиты нужны реальные цифры на настоящих
данных, не на синтетике!

## Как запустить

```bash
pip install pandas numpy scikit-learn matplotlib seaborn
python3 bank_scoring.py
```

## Что внутри пайплайна (соответствие пунктам методички)

- 2.3-2.5: загрузка, просмотр структуры, удаление пропусков
- 2.7-2.8: отбор признаков (job, marital, default, housing, loan, poutcome),
  one-hot кодирование через `pd.get_dummies`
- 2.9-2.11: кодирование меток (yes/no → 1/0), обучение LogisticRegression
- 2.13, 3.1-3.3: матрица ошибок, precision/recall/F1, ROC-AUC
- 3.4: сравнение с GradientBoostingClassifier
