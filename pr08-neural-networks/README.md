# Практическая работа 8. Нейросетевые модели машинного обучения.

**Цель:** получение практических навыков создания, обучения и оценки
качества нейросетевых моделей машинного обучения.

## Содержимое

| Файл | Что реализовано |
|---|---|
| `dense_mnist.py` | Раздел 3 — полносвязная (Dense) сеть на MNIST |
| `cnn_mnist.py` | Раздел 4 — свёрточная сеть (CNN) на MNIST, сравнение с Dense |

Также стоит зайти на https://playground.tensorflow.org/ и поэкспериментировать
с параметрами вручную (п.1.2 методички) — это отдельно от кода, руками в
браузере.

Ответы на теоретические вопросы (п.1.3, 3.6) — в `../docs/pr08_answers.md`.

## Как запустить

```bash
pip install keras tensorflow-cpu
python3 dense_mnist.py
python3 cnn_mnist.py
```

При первом запуске `keras.datasets.mnist.load_data()` скачает датасет из
интернета (~11 МБ) — нужен обычный доступ в сеть, ничего скачивать вручную
не надо.

## Архитектуры (проверено при сборке репозитория)

- **Dense:** Dense(512, relu) → Dense(10, softmax), **407 050** параметров —
  точно совпадает с методичкой.
- **CNN:** Conv2D(32)→MaxPool→Conv2D(64)→MaxPool→Conv2D(64)→Flatten→
  Dense(64,relu)→Dense(10,softmax), **93 322** параметра — тоже совпадает.
- Обе модели: loss = categorical_crossentropy, optimizer = rmsprop,
  epochs = 5 (Dense: batch_size=128, CNN: batch_size=64).
- Ожидаемое качество (из методички): Dense ≈ 0.9785 accuracy,
  CNN ≈ 0.9916 accuracy на тестовой выборке — CNN точнее за счёт того, что
  свёртка учитывает пространственную структуру изображения.
