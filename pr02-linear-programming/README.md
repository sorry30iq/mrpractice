# Практическая работа 2. Решение задач линейной оптимизации.

## Содержимое

| Файл | Задача |
|---|---|
| `task1_lopaty.py` | Совковые/штыковые лопаты — максимизация дохода |
| `task2_pricepy.py` | Прицепы/кормораздатчики — 3 подзадачи (max количество, max выручка, min себестоимость) |
| `task3_nasosy.py` | Топливные/водяные насосы — целочисленное ЛП (milp), максимизация прибыли |
| `task4_bioadd.py` | Биодобавки "Телец"/"Овен" — максимизация прибыли |

Все задачи решены через `scipy.optimize.linprog` (задача 3 — через `milp`,
т.к. количество насосов должно быть целым числом).

## Как запустить

```bash
pip install scipy
python3 task1_lopaty.py
python3 task2_pricepy.py
python3 task3_nasosy.py
python3 task4_bioadd.py
```

## Результаты (проверено при сборке репозитория)

- Задача 1: 4000 совковых + 7000 штыковых лопат, доход 590 000 руб.
- Задача 2: а) max количество — 11 688 прицепов; б) max выручка — 1200
  прицепов + 8448 кормораздатчиков; в) min себестоимость — 1200 прицепов,
  0 кормораздатчиков.
- Задача 3: 0 топливных + 3 водяных насоса, прибыль 600 руб.
- Задача 4: 0 кг "Телец" + 63 кг "Овен", прибыль 453.6 тыс. руб.

`linprog` по умолчанию решает задачу МИНИМИЗАЦИИ — для максимизации во всех
скриптах коэффициенты целевой функции берутся со знаком минус, а на выходе
результат снова инвертируется (см. комментарии в коде).
